Scenario 1: Import bank transactions

1. User logs into the application.
2. User opens Transactions.
3. User selects "Import CSV".
4. User uploads a CSV file.
5. System validates the file.
6. System detects the CSV structure.
7. System shows a preview of transactions.
8. User confirms the import.
9. System creates transactions.
10. Imported transactions become visible in the user's transaction list.

Scenario 2: Categorise transaction

1. User opens a transaction.
2. User selects a category.
3. System validates that the category belongs to the user
   or is available to the user's family.
4. System updates the transaction.
5. Transaction appears under the selected category.

Scenario 3: Create family group

1. User creates a family group.
2. User becomes the family owner.
3. User invites another registered user.
4. Invited user accepts the invitation.
5. Both users become members of the family.
6. Access to shared financial data is controlled by permissions.
7. User can see his own Dashboard with transactions and report and famaly Dashboard.
