# Budget Manager

## Problem

People often have financial transaction data exported from
different banking systems as CSV files. These files are difficult
to analyse consistently and manually categorising transactions
is time-consuming.

## Goal

Budget Manager is a web application that allows users to import
financial transactions from CSV files, categorise them and analyse
their income and expenses.

## Target users

- Individual users
- Family groups

## Core functionality

Users should be able to:

- create an account
- authenticate
- import transactions from CSV
- create transaction manually
- view imported transactions
- categorise transactions
- edit transaction information
- create categories
- analyse income and expenses
- create budgets
- view reports

Family users should be able to:

- create a family group
- invite other users
- share selected financial data
- manage family membership

## Non-goals

The application will not:

- connect directly to banks
- execute payments
- provide financial advice
- act as a banking application
